# SkillBridge – Career Roadmap Platform

## Overview

SkillBridge is a web application that helps students explore technology career paths through structured learning roadmaps. The platform provides career descriptions, required skills, recommended projects, certifications, and progress tracking.

This project is aligned with **United Nations Sustainable Development Goal (SDG) 4: Quality Education**.

---

## SDG Alignment

### SDG 4 – Quality Education

Many students struggle to find clear career guidance and learning resources. SkillBridge helps learners understand what skills, projects, and certifications are needed for different technology careers.

---

## Problem Statement

Students often face difficulty in:

* Choosing a career path
* Understanding which skills to learn
* Finding relevant projects
* Identifying useful certifications
* Tracking their learning progress

This lack of structured guidance can slow career growth and create confusion among learners.

---

## Solution

SkillBridge provides a structured career guidance platform where users can:

* Select a career path
* View required skills
* Explore recommended projects
* Discover relevant certifications
* Track learning progress

## Running the Project Locally

### Frontend

Open a terminal inside the client folder:

```bash
cd client
npm start
```

Frontend URL:

http://localhost:3000

### Backend

Open a terminal inside the server folder:

```bash
cd server
node server.js
```

Backend URL:

http://localhost:5000

API Endpoint:

http://localhost:5000/api/careers
